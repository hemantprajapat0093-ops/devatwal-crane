## 🐳 डॉकर में चलाने के निर्देश (Run with Docker)

### विकल्प 1: Docker Compose (सर्वाधिक सरल)
प्रोजेक्ट फोल्डर `C:\Users\heman\Desktop\devatwal-crane-service` में टर्मिनल खोलें और चलाएं:
```bash
docker compose up -d --build
```

### विकल्प 2: Docker CLI
```bash
# 1. इमेज बिल्ड करें
docker build -t devatwal-crane-service .

# 2. कंटेनर रन करें
docker run -d --name devatwal_portal -p 3000:3000 -v ${PWD}/data:/app/data devatwal-crane-service
```

कंटेनर चालू होने के बाद ब्राउज़र में खोलें:
👉 **http://localhost:3000**

कंटेनर स्टेटस व लॉग्स जांचने के लिए:
```bash
docker ps
docker logs -f devatwal_crane_service_portal
```
